# arcane-guardians-and-loot

A mystical tower-defense game concept built with TypeScript, React, TanStack Start, Supabase, and custom game-themed UI assets.

The project presents a fantasy defense experience where players protect a sanctum with magical towers, resource management, waves, and a polished landing/game interface.

## Highlights

- Painterly fantasy landing page and game presentation
- Tower-defense themed gameplay structure
- Wave controls, lives, gold, and combat status UI
- Game HUD with pause, speed, and wave actions
- Fantasy battlefield and unit/enemy assets
- Modern React routing and component structure
- Supabase integration scaffolding
- Responsive UI component system

## Tech Stack

- TypeScript
- React 19
- TanStack Start
- TanStack Router
- TanStack Query
- Supabase
- Vite
- Tailwind CSS
- Radix UI primitives
- Lucide React

## Notable Source Areas

- `src/routes/index.tsx` - landing page for the game
- `src/components/game/HUD.tsx` - gameplay HUD and wave controls
- `src/assets/` - battlefield, tower, enemy, and hero assets
- `src/lib/game/` - game content and engine logic

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
